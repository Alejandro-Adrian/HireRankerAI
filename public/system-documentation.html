💾 Database Schema (Supabase PostgreSQL)

Core Tables

Table Purpose Key Columns
users User accounts & authentication id, email, password_hash, is_verified, created_at
rankings Job ranking records id, created_by, title, description, status, created_at
applications Job applications id, ranking_id, applicant_name, email, resume_path, score, rank_position
interview_sessions Video interview records id, application_id, meeting_id, status, start_time, end_time, recording_url
video_sessions Video call sessions id, interview_id, duration, transcript, summary, feedback
application_files Uploaded documents id, application_id, file_url, file_type, file_size
notifications User notifications id, user_id, message, type, is_read, created_at
transcription_results Interview transcriptions id, video_session_id, transcript_text, summary, keywords

Database Features

  • Row-Level Security (RLS): Data access is controlled based on user roles
  • Real-time Subscriptions: Live updates for notifications and analytics
  • Full-Text Search: Search across applications and rankings
  • Indexes: Optimized queries for fast data retrieval
  • Relationships: Foreign keys ensure data integrity
Database URL: Set via environment variable DATABASE_URL or SUPABASE_URL

🔗 External Integrations & Services

1. Supabase (PostgreSQL Database)

Purpose

Primary database for all application data, user management, and real-time subscriptions

Configuration

  • NEXT_PUBLIC_SUPABASE_URL - Supabase project URL
  • NEXT_PUBLIC_SUPABASE_ANON_KEY - Anon API key for client
  • SUPABASE_SERVICE_ROLE_KEY - Service role key for server operations

Usage

Client: createBrowserClient() | Server: createServerClient()

2. Vercel Blob Storage

Purpose

Cloud storage for resume files and interview recordings

Configuration

  • BLOB_READ_WRITE_TOKEN - Authentication token for blob storage

Buckets

  • application-files/ - Resumes and documents
  • recordings/ - Video interview recordings

3. VideoSDK.live

Purpose

Real-time video conference platform for conducting interviews

Configuration

  • VIDEOSDK_API_KEY - VideoSDK API key
  • VIDEOSDK_SECRET - VideoSDK secret for token generation

Endpoints

  • /api/video-sdk/create-meeting - Create meeting
  • /api/video-sdk/create-token - Generate participant token

4. Deepgram (Speech-to-Text)

Purpose

Real-time speech recognition and audio transcription

Configuration

  • DEEPGRAM_API_KEY - API key for Deepgram service

Models

  • nova-2: Fast, accurate speech recognition

5. AssemblyAI (Transcription)

Purpose

Batch transcription of recorded interviews with speaker diarization

Configuration

  • ASSEMBLYAI_API_KEY - API key for AssemblyAI

Endpoints

  • https://api.assemblyai.com/v2/transcript - Submit transcription job

6. Grok (XAI) - AI Analysis

Purpose

AI-powered candidate analysis, interview summarization, and scoring

Configuration

  • XAI_API_KEY - XAI API key for Grok access

Model

  • grok-4: Latest Grok model for analysis

Use Cases

  • Resume scoring and ranking
  • Interview transcription summarization
  • Candidate feedback generation
  • Natural language queries on data

7. Resend (Email Service)

Purpose

Transactional email delivery for notifications and invitations

Configuration

  • RESEND_API_KEY - API key for Resend

Email Types

  • Email verification
  • Password reset
  • Interview invitations
  • Application status updates

8. OCR API (Resume Parsing)

Purpose

Extract text and structured data from uploaded resume files

Configuration

  • OCR_API_KEY - API key for OCR service

9. Neon Database (Backup/Alternative)

Purpose

PostgreSQL database alternative for serverless operations

Configuration

  • POSTGRES_URL - Database connection string
  • POSTGRES_URL_NON_POOLING - Non-pooling connection
